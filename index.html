TRIGGER CONFIG

G HUB 宏触发设置

复制或下载 Lua 前必填；这些设置不会写入谱子分享文件。

变调键映射 Lua 模拟编号：左 1／中 2／右 3

原因：G HUB Lua 的停止检测使用 IsMouseButtonPressed 状态轮询；这里固定使用 4/5 停止状态编号，避免与默认的 1–3 变调模拟编号混淆。

开始键触发一次播放；停止键请选择 4 或 5。停止时会释放正在按住的琴键和变调键。

FILE_CHECK.EXE — MACRO SAFETY
11 · FILE SAFETY

宏文件安全自查

本工具导出的文件只包含按键、等待与触发事件。网上流传的第三方宏，尤其是付费宏，不一定是同一回事；拿到任何宏文件后，都可以按下面四步核对。

01 · EXPORT CONTENTS

本工具导出的文件里有什么

  • Logitech G HUB 的 .lua 是唯一的代码格式，只调用 PressKey、ReleaseKey、ReleaseMouseButton、Sleep、AbortMacro 这类按键 API。
  • Razer .xml、迈从 .json、ROG .gmac 是数据格式，只记录按键与毫秒延时，本身无法执行代码。
  • 全部格式都不联网、不读写文件、不读取剪贴板、不调用其它进程，也不需要任何“激活”步骤。
  • 导出前可先点「复制 Lua」，粘贴到文本编辑器里逐行看完，再导入鼠标软件。
02 · DANGER TOKENS

拿到第三方脚本先搜关键字

用系统自带记事本打开文件，按 Ctrl+F 搜索下面的字样。出现任意一项，说明该脚本可以执行命令、读写文件或联网，是否继续使用需要你自行判断。

os.execute io.open io.popen require loadstring dofile socket http WinHttp DownloadFile while true

口琴宏只应该有按键、延时和触发判断。看不懂的脚本不要导入，也不要为了“先试试”关闭杀毒软件。

03 · REFUSE THESE

遇到这些要求直接拒绝

  • 要求先安装「激活器」「卡密工具」「专用驱动」等程序才能使用宏。
  • 要求开启远程协助，或让你把电脑交给对方操作。
  • 索要游戏账号、邮箱、短信验证码、登录令牌，或让你登录对方提供的页面。
  • 要求关闭杀毒软件与 Windows Defender，或索取与宏无关的系统权限。
  • 用压缩包密码、群内解压、二次付费来交换文件。

任何一条都说明对方要索取的东西已经超出了宏文件本身。

04 · DOWNLOAD SOURCES

只从可信来源下载

  • 录制助手请只从本页下载入口或 GitHub Release 获取；网盘转存和群文件的安装包无法核对来源。
  • GitHub Release 会附带该版本安装包的 SHA-256，可用 certutil -hashfile 文件名 SHA256 比对后再运行。
  • 宏文件是纯文本，记事本就能查看，不需要任何“专用查看器”。拒绝让你查看内容、只给加密包的做法。
  • 录制助手按说明需要以管理员身份运行，这是为了让目标宏软件捕获输入；除此之外，官方组件不会再要求额外权限或安装其它程序。
!

文件安全不等于使用合规 即使脚本本身干净，在游戏中自动演奏仍可能违反目标游戏、平台或服务器的规则。请先阅读上方免责声明，并自行确认使用环境。

!

雷蛇兼容说明 没有本机导出样本时，Synapse 3/4 XML 仅按公开社区结构生成。若导入失败，请先在你的版本中录制一个单键宏并导出，再用其作为格式校准样本。

!

迈从兼容说明 MCHOSE JSON 按提供的迈从导出样例生成。不同驱动版本或外设的宏能力可能不同；若导入失败，请用该版本录制并导出一个单键宏后与生成文件比对。

!

ROG 兼容说明 GMAC 格式按 Armoury Crate 当前导出结构生成。不同版本或外设的宏能力可能不同；若导入失败，请用该版本录制并导出一个单键宏后与生成文件比对。

ABOUT.EXE — DELTA HARMONICA MACRO
13 · ABOUT THE TOOL

三角洲口琴宏：从 MIDI 转宏到自动演奏

三角洲口琴演奏家是一款在浏览器中运行的口琴宏生成器，适合把《三角洲行动》的口琴数字简谱转换成可导入鼠标软件的宏文件。你可以直接输入简谱、导入 MIDI，或从曲库载入现成曲目，再试听旋律、调整 BPM 和导出宏。

三角洲口琴数字简谱转宏

支持普通音、升降音、八度、附点、休止和精确拍数输入，并提供三角洲键盘模式，方便校对按键与毫秒时值。

MIDI 转宏与口琴自动演奏

导入 MIDI 后可选择主旋律音轨和演奏片段，生成口琴谱并在页面内预览，适合制作口琴自动演奏曲目。

多种宏软件导出

导出方式按顺序统一展示，可导出通用录制助手、Logitech G HUB Lua、Razer Synapse XML、迈从 MCHOSE JSON 和 ROG Armoury Crate GMAC 等格式，并显示每种方法适用的品牌。
