TRIGGER CONFIG

G HUB 宏触发设置

复制或下载 Lua 前必填；这些设置不会写入谱子分享文件。

变调键映射 Lua 模拟编号：左 1／中 2／右 3

单次播放：按下后完整播放一次。变调键填写的是 Lua 的模拟按键编号，不是原始鼠标事件编号：模拟中键为 2、右键为 3；播放键和停止键不能与这些映射重复。播放卡住时可用全局停止键中止当前 Lua。

G

Logitech G HUB

Lua 脚本 · 手动粘贴

按上方设置生成可审阅的 Lua。可额外指定全局停止键，脚本会在停止时释放正在按住的琴键和变调键。

R

Razer Synapse 3

XML · 实验性兼容

仅导出事件序列；导入后请在 Synapse 3 的 Macro 模块内手动绑定鼠标键和触发模式。Synapse 3 文件不能导入 Synapse 4。

R4

Razer Synapse 4

XML · 实验性兼容

仅导出事件序列；在 Macro 列表的更多菜单中选择 Import，导入后再手动绑定鼠标键和触发模式。

ROG

ROG Armoury Crate

GMAC · 宏配置文件

生成可导入的 Armoury Crate 宏事件。导入后请将宏绑定到支持宏功能的 ROG 外设按键；默认设置为单次播放。

KB

手动输入宏

三角洲键盘模式 · 谱子预览

以「按键 / 毫秒」展示当前曲谱，便于在支持手动录入的宏工具中逐项填写。

!

雷蛇兼容说明 没有本机导出样本时，Synapse 3/4 XML 仅按公开社区结构生成。若导入失败，请先在你的版本中录制一个单键宏并导出，再用其作为格式校准样本。

!

ROG 兼容说明 GMAC 格式按 Armoury Crate 当前导出结构生成。不同版本或外设的宏能力可能不同；若导入失败，请用该版本录制并导出一个单键宏后与生成文件比对。
